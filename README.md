# TogetherPay — เว็บแอปบันทึกค่าใช้จ่ายคู่รัก (เนิร์ส & พี)

เว็บแอปพลิเคชันสำหรับคู่รัก (**เนิร์ส** & **พี**) ใช้บันทึกค่าใช้จ่ายร่วมกัน ค่าใช้จ่ายส่วนตัว ค่าใช้จ่ายเรียกเก็บรายเดือน (พร้อมเช็คลิสต์และแนบสลิปโอนเงิน) และ Dashboard สรุปยอดโอนคืนสุทธิแบบเรียลไทม์

## ฐานข้อมูล Firebase

## โมดูลหลัก
1. **โมดูล 1: บันทึกค่าใช้จ่ายร่วมกัน (ร่วมกัน)**
   - ตัวกรองเดือนและปี (เปิดมาจะเลือกเดือนและปีปัจจุบันเสมอ)
   - กรอกจำนวนเงิน (บาท), ชื่อรายการ, หมวดหมู่ (`น้ำมัน`, `อาหาร`, `ที่พัก`, `ช้อปปิ้ง`, `ท่องเที่ยว`)
   - เลือกคนออกเงิน (`เนิร์ส`, `พี`) และการหารเงิน (`หาร 2`, `เนิร์สคนเดียว`, `พีคนเดียว`)
   - เชื่อมต่อพิกัด **GPS** ปัจจุบันพร้อมแปลงชื่อสถานที่อัตโนมัติและลิงก์ Google Maps
2. **โมดูล 2: ค่าใช้จ่ายส่วนตัว**
   - เลือกบันทึกแยกกระเป๋า (`เนิร์ส`, `พี`)
   - ปุ่มเพิ่มค่าใช้จ่ายที่ตั้งวันที่เป็น **วันนี้** ให้อัตโนมัติเสมอ
3. **โมดูล 3: ค่าใช้จ่าย เรียกเก็บรายเดือน**
   - ตั้งค่ารายการรายเดือน กำหนดเดือนเริ่มต้น-สิ้นสุด และยอดขั้นต่ำต่อเดือน
   - ตั้งค่าแชร์/หารกับอีกฝ่าย (เช่น ค่าห้อง 6,000 บาท หารคนละ 3,000 บาท)
   - เช็คลิสต์ประจำเดือน ปรับยอดจ่ายจริงรายเดือนได้ และแนบสลิปโอนเงินเมื่อจ่ายเสร็จสิ้น
4. **โมดูล 4: Dashboard**
   - ฟิลเตอร์เลือกเดือน เลือกปี และปุ่มดูภาพรวมทั้งหมด
   - 3 แท็บ: **ของพี**, **ของเนิร์ส**, และ **ร่วมกัน** พร้อมกราฟและสรุปยอดว่าใครต้องโอนคืนใคร

## การรันในเครื่อง (Local Development)
```bash
npm install
npm run dev
```

## การขึ้น GitHub และ Deploy ผ่าน Vercel
1. สร้าง Repository บน GitHub แล้วรันคำสั่ง:
   ```bash
   git remote add origin <GITHUB_REPO_URL>
   git branch -M main
   git push -u origin main
   ```
2. ไปที่ [Vercel](https://vercel.com/new) เลือก Import โปรเจกต์จาก GitHub Repository นี้ แล้วกด **Deploy** ได้ทันที
